 # QR Code and Password Generator

A simple Python mini project to generate QR codes from text, links, and passwords.

## Features
- Generate QR codes for text and links.
- Generate random passwords with optional symbols.
- Convert existing passwords into QR codes.
- Save QR codes as PNG images.
- Unique filenames for each QR code.

## Requirements
```bash
pip install qrcode[pil]
```

## Run
```bash
python main.py
``
